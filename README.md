# The Odin Project: Homepage

This project is a responsive homepage recreation built as part of the Odin Project curriculum assignment for Advanced HTML and CSS.

## Project Overview

The goal of this project was to practice building a polished landing page using semantic HTML and modern CSS techniques. This includes working with layout structure, responsive design, typography, spacing, and image styling.

## Assignment Reference

- [The Odin Project - Homepage](https://www.theodinproject.com/lessons/node-path-advanced-html-and-css-homepage)

## Features

- Responsive homepage layout
- Semantic HTML structure
- Modern styling with CSS
- Optimized image usage for quality and responsiveness
- Clean visual design inspired by the reference layout

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Alternatively, run a local web server:

```bash
python -m http.server
```

Then visit:

```text
http://localhost:8000
```
